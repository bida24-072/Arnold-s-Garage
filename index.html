📘 README — Arnold's Garage Website

Version 1.0 — A responsive, dark‑themed showcase of muscle, luxury, off‑road, and racing cars.

🚗 Features

  • Four car categories: Muscle, Luxury, Off‑Road, Racing — each with 3 representative models.
  • W3Schools‑inspired layout: clean grid, rounded cards, clear navigation, hover effects.
  • Dark garage theme: deep blacks, gold accents (#c9a03d), and subtle gradients.
  • Responsive design: adapts from desktop to mobile (flex + grid).
  • Interactive navigation: active state, hover scaling, and smooth transitions.
  • No external images: car visuals are created with CSS gradients and icons — lightweight and fast.

🛠️ Technologies Used

  • HTML5 — semantic structure
  • CSS3 — Flexbox, Grid, transitions, gradients, media queries
  • W3Schools layout principles — max‑width container, padding, rounded corners, card style

📂 File Structure

  • arnolds-garage.html — single‑file website (HTML + CSS in one).
  • No external dependencies, fonts, or images — fully self‑contained.

🚀 How to Use

  • Open the HTML file in any modern browser (Chrome, Firefox, Edge, Safari).
  • Click navigation links to jump to sections (future enhancement: anchor links).
  • Hover over car cards to see a subtle lift and gold border effect.

📝 Notes

  • Car specifications are illustrative and based on real‑world models for authenticity.
  • Designed as a single‑page template; sections are ready to be split into separate pages if needed.
  • All colors and styling follow a consistent “garage” aesthetic — dark, metallic, premium.
